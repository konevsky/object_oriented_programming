# Object-Oriented Programming Project

Проект, демонстрирующий основные принципы объектно-ориентированного программирования на Python с реализацией классов для управления товарами и категориями.

## 📋 Описание

Проект реализует систему управления каталогом товаров с двумя основными классами:
- `Product` - класс для представления товаров
- `Category` - класс для представления категорий товаров

Дополнительно реализована загрузка данных из JSON файла.

## 🚀 Классы

### BaseProduct (абстрактный класс)

Абстрактный базовый класс для всех продуктов:
- Определяет общую функциональность для каждого продукта
- Содержит абстрактные методы `__str__` и `__add__`

### BaseEntity (абстрактный класс)

Абстрактный базовый класс для сущностей:
- Общий предок для классов Order и Category
- Содержит абстрактный метод `__str__`

### CreationMixin (миксин)

Миксин для логирования создания объектов:
- Печатает информацию о создании объекта в консоль
- Реализует метод `__repr__` для отладки
- Добавлен в цепочку наследования класса Product

### Product

Атрибуты:
- `name` (str) - название товара
- `description` (str) - описание товара  
- `price` (float) - цена товара
- `quantity` (int) - количество в наличии

Наследуется от: `CreationMixin, BaseProduct`

### Category

Атрибуты:
- `name` (str) - название категории
- `description` (str) - описание категории
- `products` (List[Product]) - список товаров категории

Атрибуты класса:
- `category_count` (int) - общее количество созданных категорий
- `product_count` (int) - общее количество товаров во всех категориях

Наследуется от: `BaseEntity`

### Order (новый класс)

Атрибуты:
- `product` (BaseProduct) - товар, который был куплен
- `quantity` (int) - количество купленного товара
- `total_cost` (float) - итоговая стоимость

Функциональность:
- Валидация типа продукта и количества
- Автоматическое уменьшение количества товара на складе
- Расчет итоговой стоимости

Наследуется от: `BaseEntity`

### Smartphone (наследник Product)

Дополнительные атрибуты:
- `efficiency` (str) - производительность
- `model` (str) - модель
- `memory` (int) - объем встроенной памяти в ГБ
- `color` (str) - цвет

### LawnGrass (наследник Product)

Дополнительные атрибуты:
- `country` (str) - страна-производитель
- `germination_period` (str) - срок прорастания
- `color` (str) - цвет

## 📊 Функциональность

### Основные возможности:
1. **Создание объектов** - ручное создание товаров и категорий
2. **Автоматический подсчет** - отслеживание количества категорий и товаров
3. **Загрузка из JSON** - импорт данных из файла `data/products.json`

### Пример использования:

```python
from src.models import Product, Category, load_categories_from_json

# Ручное создание
product = Product("Ноутбук", "Игровой ноутбук", 999.99, 5)
category = Category("Электроника", "Товары для компьютеров", [product])

# Загрузка из JSON
categories = load_categories_from_json("data/products.json")
```

## 📁 Формат JSON

Файл `data/products.json` должен иметь следующую структуру:

```json
[
  {
    "name": "Название категории",
    "description": "Описание категории",
    "products": [
      {
        "name": "Название товара",
        "description": "Описание товара", 
        "price": 100.50,
        "quantity": 10
      }
    ]
  }
]
```
